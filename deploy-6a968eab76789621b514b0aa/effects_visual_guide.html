🎯 Customization Options

Rotation Intensity

Adjust how dramatically the cabinet rotates based on cursor position.

const rotX = mouseY * 30;
const rotY = mouseX * 45;

Higher numbers = more rotation. Try: 30→50 for extreme, 30→15 for subtle

Auto-Rotation Speed

Control how fast the cabinet spins during auto-rotation on hover.

rotY += 3; // frames per interval

Try: 1 (slow), 3 (default), 5 (fast), 8 (very fast)

Zoom Scale

Adjust how much the cabinet zooms in when you hover.

scale(1.15) // 1.0 = no zoom, 1.5 = 50% larger

Recommended: 1.05 (subtle), 1.15 (default), 1.25 (dramatic)

Glow Intensity

Control the red glow brightness around the cabinet.

rgba(192,21,42,0.4) // last value = opacity

Try: 0.2 (subtle), 0.4 (default), 0.8 (intense), 1.0 (maximum)

Animation Response Time

How quickly the rotation responds to mouse movement.

transition: transform 0.08s ease-out;

0.05s (instant), 0.08s (default), 0.15s (smooth), 0.25s (sluggish)

Reset Animation Speed

How long it takes to return to original position.

transition: 'all 0.7s cubic-bezier(...)';

0.3s (snappy), 0.7s (default), 1.2s (graceful), 2s (slow)
