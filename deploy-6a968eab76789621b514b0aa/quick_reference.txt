║                          CUSTOMIZATION POINTS                                ║
╚══════════════════════════════════════════════════════════════════════════════╝

🎯 ROTATION INTENSITY
   File: script.js, Section 6B
   Look for: const rotX = mouseY * 30;
             const rotY = mouseX * 45;
             const tiltZ = mouseX * 10;
   Change these numbers to adjust intensity

🎯 AUTO-ROTATION SPEED
   File: script.js, Section 6B
   Look for: rotY += 3;
   Change to: rotY += 5; (faster) or rotY += 1; (slower)

🎯 ZOOM SCALE
   File: script.js, Section 6B
   Look for: scale(1.15)
   Change to: scale(1.20) for more zoom, scale(1.05) for less

🎯 GLOW COLOR
   File: style.css
   Look for: rgba(192,21,42,0.X)
   This is your Redheart red - adjust the last number (opacity)
   Examples: rgba(192,21,42,0.4) = less glow
            rgba(192,21,42,0.8) = more glow

🎯 ANIMATION SPEED
   File: style.css or script.js
   0.08s = very fast response
   0.7s = slow return animation
   Adjust these time values as needed
